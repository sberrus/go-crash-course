## Cosas intersantes

Golang tiene Garbage Collector para le manejo de la memoria de forma dínamica parecido al que tiene por ejemplo las VM de Java, pero no viene con una VM, por lo que el binario que ejecuta es código binario del procesador donde haya sido compilado.

Esta entre medias entre los lenguajes compilados y los que cuentan con una VM y GC, esto hace que el consumo y el uso de la memoria comparado con la JVM sea 100 veces menor.

Simplificandolo, estaría entre medias entre Java y Rust/C por ejemplo.
